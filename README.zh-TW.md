## 精選作品

### [Hybrid RAG](https://yuchan27.github.io/zh/?lang=zh#work)

結合關鍵字搜尋、向量搜尋與重排序的檢索後端，為 LLM 回覆準備相關上下文。

### [Realtime Voice](https://yuchan27.github.io/zh/?lang=zh#work)

透過雙向 WebSocket 橋接 Twilio 音訊串流與 Realtime 模型，實作電話型語音助理整合。

### [Health Data Pipeline](https://yuchan27.github.io/zh/?lang=zh#work)

整理多來源健康服務據點資料，完成去重、欄位正規化、分類對應與 GeoPoint 對齊，供 Back4App 匯入。

### [FoodLens AI](https://github.com/yuchan27/Ingredient-AI)

本地優先的飲食分析 App，提供影像分析、可編輯的營養紀錄、雲端同步與伺服器端使用額度控管。

### [PyroDetector](https://github.com/yuchan27/Vision-Communication-Routing-based-on-Sensor-Fusion)

以 YOLOv11 進行火焰與煙霧偵測實驗，包含資料集參考，以及圖片與影片示範。

### [Cat Future Lab](https://github.com/yuchan27/Anime_Cat)

將自然語言請求轉成經過驗證的操作，再更新應用狀態的實驗性網頁介面。
