## Selected work

### Hybrid RAG / DigiMed LineOA
A multi-tenant clinic LINE OA backend that combines keyword search, vector retrieval, reranking and LLM response generation. The retrieval flow uses PostgreSQL / pgvector and supports fallback behavior when reranking is unavailable.

**Stack:** TypeScript / PostgreSQL / pgvector / Hybrid RAG / BGE Reranker

### Realtime Voice-to-Voice
Phone-based AI voice assistant experiments using Twilio Voice, Media Streams and Realtime APIs, with bidirectional audio streaming over WebSocket.

**Stack:** Node.js / WebSocket / Twilio / Realtime API

### Health Resource Data Pipeline
Healthcare resource data processing for Taiwan: source fusion, deduplication, address / phone normalization, category mapping, GeoPoint alignment and Back4App import preparation.

**Stack:** Back4App / Parse / CSV / JSON / GeoPoint / Data Cleaning

### [FoodLens AI / 食伴 AI](https://github.com/yuchan27/Ingredient-AI)
A local-first diet analysis app built with Flutter, Firebase, Vercel and Gemini, covering food-image understanding, nutrition analysis, cloud synchronization and backend quota control.

### [PyroDetector](https://github.com/yuchan27/Vision-Communication-Routing-based-on-Sensor-Fusion)
Computer vision project exploring fire and smoke detection with YOLOv11.

### [Cat Future Lab](https://github.com/yuchan27/Anime_Cat)
An AI interaction experiment that converts natural-language intent into validated structured actions before updating application state.
